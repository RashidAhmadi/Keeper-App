# Keeper App

A simple and modern note-taking application built with React and Vite.

## 🚀 Features

* Create and display notes
* Reusable React components
* React Router navigation
* Responsive Navbar and Footer
* Modern UI styling with CSS
* Fast development using Vite

---

## 🛠️ Technologies Used

* React.js
* Vite
* React Router DOM
* JavaScript (ES6+)
* CSS3

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/keeper-app.git
```

Navigate into the project folder:

```bash
cd keeper-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open in browser:

```text
http://localhost:5173/
```
